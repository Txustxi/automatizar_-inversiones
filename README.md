# OpoRentable PWA

Aplicación PWA funcional para estudio de oposiciones, con progreso local, mini tests y modo premium demo.

## Scripts
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm test`

## Estado
Base funcional migrada a TypeScript + Vite, lista para integrar backend (Supabase), pagos reales y analítica.
